# Live logs

Минималистичный WebSocket-сервер для просмотра логов по комнатам в браузере.
Сообщения хранятся только в оперативной памяти и исчезают после перезапуска.

## Запуск

Один раз настройте локальный домен на NixOS:

```bash
sudo ./scripts/setup-nixos.sh
```

Затем запускайте приложение:

```bash
docker compose up --build
```

Интерфейс: <http://ws.local>

Демонстрация передачи позиции мыши: <http://ws.local/mouse.html>
Комнату можно выбрать параметром, например `mouse.html?room=demo`.

## Отправка логов

Подключите приложение к комнате и отправляйте обычные строки или JSON с событием:

```text
ws://ws.local/api/logs?room=backend
```

Пример для браузера или приложения с WebSocket API:

```js
const logs = new WebSocket('ws://ws.local/api/logs?room=backend')

logs.addEventListener('open', () => {
  logs.send('Сервер запущен')
  logs.send(JSON.stringify({
    event: 'auth.login',
    message: 'Пользователь вошёл',
    data: { userId: 42 },
  }))
})
```

Обычные строки относятся к событию `log`. Найденные события можно включать и
выключать отдельно для каждой комнаты на странице <http://ws.local/events>.
Настройки сохраняются локально в браузере.

Непрочитанные сообщения отмечаются в панели голубым цветом. Комната становится
активной после клика, а сообщения считаются прочитанными только после появления
в её видимой области. Позиция прочтения также сохраняется в браузере.

Кнопка `½` в заголовке уменьшает комнату до половины высоты и создаёт место во
втором ряду. Верхний и нижний ряды заполняются независимо. Кнопка `↕` возвращает
комнату на полную высоту, если для неё достаточно места. При следующем уменьшении
комната возвращается на прежнюю строку и позицию.

Боковая панель содержит дерево `контур → сервер → экран → комната`. Контуры и
серверы — только локальная организация панели: отправитель по-прежнему передаёт
лишь уникальное имя комнаты и событие. У каждого сервера есть неудаляемый экран
`Основной`; остальные экраны можно создавать, переименовывать и удалять.

Открытая комната принадлежит одному экрану во всём дереве и возвращается в список
свободных после закрытия либо удаления родительского экрана, сервера или контура.
Вся структура и раскладки сохраняются в `localStorage`.

Открытые экраны отображаются вкладками над рабочей областью. Закрытие вкладки не
удаляет экран: его можно снова открыть из дерева. Каждый сервер помнит собственный
набор вкладок и активный экран.

Комната создаётся при подключении. В памяти остаются последние 500 сообщений
каждой комнаты. Значение можно изменить через `ROOM_HISTORY_SIZE` в
`compose.yaml`.

## Локальная разработка

В двух терминалах:

```bash
npm run server
```

```bash
npm run dev
```
